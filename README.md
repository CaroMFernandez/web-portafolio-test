# 3D Developer Portfolio - Carolina Fernández

This is a personal portfolio featuring a 3D interactive scene developed for project. The site showcases a custom-made developer setup modeled in Blender and integrated using Three.js.

## 🚀 Features
- **3D Interactive Scene:** High-performance GLB model with OrbitControls (Zoom/Rotate).
- **Glassmorphism UI:** Modern interface designed with HTML5 and CSS3.
- **Responsive Design:** Optimized for desktop and mobile devices.
- **Interactive Modals:** Dynamic sections for "About Me", "Skills", and "Projects".

## 🛠️ 3D Model Details
The setup was modeled in **Blender** and exported as a **GLB** file. 
- **Custom Modeled:** Desk, Monitor, Keyboard, bed, PC.
- **Imported Assets:** Minecraft Mug, Ergonomic Chair, Gamer Mouse.

## 📦 Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
- **3D Engine:** Three.js (WebGL).
- **Assets:** Blender, Google Fonts (Outfit).
